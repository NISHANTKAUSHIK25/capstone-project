
Gas Leakage Detection System 🚨

1. Introduction

This project is a Gas Leakage Detection System made using Arduino UNO. It detects gas in the air and gives an alert when the gas level goes above a set limit.

2. Components Used

- Arduino UNO
- Gas Sensor
- LED
- Buzzer
- Breadboard
- Jumper Wires

3. Working

The gas sensor detects gas in the air and sends a signal to Arduino. Arduino checks the sensor reading. If the reading crosses the set limit, the LED turns ON and the buzzer gives an alert.

4. Applications

- Gas leakage warning
- Home safety awareness
- Gas monitoring
